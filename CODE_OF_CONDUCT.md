# Code of Conduct

## Purpose

Carrigan Software Solutions LLC is committed to maintaining a professional, respectful, and productive environment for everyone who participates in this project.

This repository is intended to support constructive collaboration. Participation in this project, including issues, pull requests, discussions, comments, and other interactions, is conditioned on compliance with this Code of Conduct.

## Expected Behavior

All participants are expected to:

- Be respectful and professional.
- Focus on the substance of technical and project-related discussion.
- Assume good faith unless there is a clear reason not to.
- Accept feedback gracefully.
- Keep criticism constructive and specific.
- Respect differences in experience, skill level, and perspective.
- Help maintain a discussion environment that is useful to the project.

## Unacceptable Behavior

The following behavior is not allowed:

- Harassment, abuse, threats, or intimidation.
- Personal attacks, insults, name-calling, or hostile conduct.
- Discriminatory or hateful language or conduct.
- Trolling, baiting, flamebait, or deliberately disruptive behavior.
- Repeated off-topic, inflammatory, or bad-faith arguments.
- Publishing or threatening to publish another person's private, confidential, or identifying information without permission.
- Impersonation or other deceptive conduct.
- Spam, solicitation, or unrelated promotional content.
- Knowingly submitting malicious code, intentionally harmful content, or deliberately misleading technical claims.

## Scope

This Code of Conduct applies to all interactions in this repository and related project spaces under the control of Carrigan Software Solutions LLC, including:

- Issues
- Pull requests
- Discussions
- Code reviews
- Wiki or documentation contributions
- Any other project communication channels that may be used for this project

## Reporting

To report a violation of this Code of Conduct, please use the GitHub **Email us** feature associated with this project or its maintainer profile rather than opening a public issue.

Reports should include enough detail to allow a reasonable investigation.

All reports will be reviewed in good faith. Carrigan Software Solutions LLC may, in its discretion, maintain confidentiality to the extent reasonably possible, but cannot guarantee complete confidentiality in every circumstance.

## Enforcement

Carrigan Software Solutions LLC reserves the right to interpret and enforce this Code of Conduct in its sole discretion.

Possible responses include, without limitation:

- Requesting a change in behavior
- Removing comments, issues, pull requests, or other content
- Closing discussions or pull requests
- Restricting participation
- Temporarily or permanently banning a participant from the project

## No Right to Participate

Participation in this project is a revocable privilege, not a right. Carrigan Software Solutions LLC may restrict, suspend, or terminate participation at any time, with or without prior notice, when deemed necessary to protect the project or its participants.

## Changes

Carrigan Software Solutions LLC may revise this Code of Conduct at any time by updating this file. Continued participation in the project after changes are posted constitutes acceptance of the revised terms.
