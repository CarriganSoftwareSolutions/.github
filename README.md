# Carrigan Software Solutions LLC GitHub Community Health Files

This repository contains the default GitHub community health files, templates, and contribution policies for repositories owned by **Carrigan Software Solutions LLC**.

These files are intended to provide consistent baseline guidance across company repositories, including contribution expectations, conduct standards, security reporting instructions, and related project-governance materials.

## Purpose

This repository exists to centrally manage shared repository-level policy files for Carrigan Software Solutions LLC projects.

Depending on the needs of a specific repository, these defaults may include items such as:

- Code of conduct
- Security policy
- Contributing guidelines
- Pull request templates
- Issue templates
- Other GitHub community health files supported by GitHub

## How These Files Apply

GitHub uses supported files in this repository as **default community health files** for other repositories owned by Carrigan Software Solutions LLC when those repositories do not define their own repository-specific versions.

If an individual repository includes its own file for a given policy or template, that repository-specific file takes precedence over the default maintained here.

## Repository Scope

This repository is primarily administrative and policy-focused. It is not intended to serve as a software project, package, or product repository.

## Contribution and Policy Notes

Policies defined here are intended to support company-owned repositories, but individual repositories may impose additional or different requirements where appropriate.

Contributors should always review the files and documentation present in the specific repository to which they intend to contribute.
